# German Academic AI-Text Detector

A detector that tells whether a German academic text was **written by a human**, **generated by AI**, or **written by a human and polished by AI**. Built from scratch: from collecting the data to training and comparing seven models.

**Result: the best models classify about 97% of the test texts correctly** and wrongly flag only about 5% of human texts. For comparison, GPT-6 Luna, simply asked to classify the texts, gets 51.7% and wrongly flags 43% of human texts. The strongest model overall is **mmBERT-base**: it also holds up on texts from completely different sources (see below).

**Models on Hugging Face:** [mmBERT-small](https://huggingface.co/aliissa824/german-academic-ai-text-mmbert-small) · [XLM-RoBERTa base](https://huggingface.co/aliissa824/german-academic-ai-text-xlm-roberta-base) · [DistilBERT German](https://huggingface.co/aliissa824/german-academic-ai-text-distilbert-german) · [TF-IDF](https://huggingface.co/aliissa824/german-academic-ai-text-tfidf)

> **Status:** the data pipeline, seven models and the model comparison are done. Error analysis, reinforcement learning and deployment come next.

> **Group work.** This project was done as group work. ## At a glance

- **30,629 texts** in three balanced classes: human, AI-generated, AI-assisted
- **10,227 human texts** from **4,121 documents** (SSOAR, peDOCS, Refubium), published 1990–2022
- AI texts from **four AI models**: GPT-5.6 Luna, GPT-6 Luna, Gemini 3.8 Flash, DeepSeek V4 Flash
- Train / validation / test **split by document**, so no paper appears in two splits
- **Six trained models** and **one zero-shot LLM baseline**, compared on the same test set
- A second test on **texts from new sources** (Wikipedia, Wikinews and more)

## The three classes

| Label | Class | What it is |
|---|---|---|
| 0 | `human` | Original text from a German academic paper published 1990–2022, before AI writing tools were widespread |
| 1 | `ai_generated` | A new text on the same topic, written by an AI model |
| 2 | `ai_assisted` | The human text, rewritten and polished by an AI model |

The third class is the hard one: an AI-assisted text keeps the human's content and structure, and only the wording changes.

## Results

All models on the same 2,737 test texts:

| Model | Accuracy | Human texts wrongly flagged |
|---|---|---|
| GPT-6 Luna, zero-shot | 51.7% | 42.6% |
| [DistilBERT German](https://huggingface.co/aliissa824/german-academic-ai-text-distilbert-german) | 91.3% | 20.1% |
| [TF-IDF + logistic regression](https://huggingface.co/aliissa824/german-academic-ai-text-tfidf) | 91.6% | 8.5% |
| [XLM-RoBERTa base](https://huggingface.co/aliissa824/german-academic-ai-text-xlm-roberta-base) | 92.8% | 17.8% |
| [mmBERT-small](https://huggingface.co/aliissa824/german-academic-ai-text-mmbert-small) | 96.3% | 4.6% |
| **mmBERT-base** | **96.6%** | 5.6% |
| GELECTRA-large | 96.9% | 4.7% |

### On texts from new sources

Hassan also tested the models on 869 texts from sources they had never seen: German Wikinews, Wikipedia, Wikivoyage and Wikibooks, with AI partners from the same four AI models ([his step 14](https://github.com/HassanHijaze/german-ai-text-detector-from-scratch/tree/main/14_ood-model-comparison)):

| Model | Accuracy | Human texts wrongly flagged |
|---|---|---|
| TF-IDF + logistic regression | 79.4% | – |
| mmBERT-small | 81.1% | 51.0% |
| DistilBERT German | 89.4% | 19.3% |
| XLM-RoBERTa base | 91.8% | 17.2% |
| GELECTRA-large | 96.3% | 7.2% |
| **mmBERT-base** | **96.6%** | **3.4%** |

These are Hassan's own runs of each model. mmBERT-base keeps its accuracy on the new texts, while mmBERT-small, nearly as good on academic texts, wrongly flags half of the new human texts. **That makes mmBERT-base the strongest model of the project.**

## What we found

- **An LLM can't just be asked.** Even with a clear definition of each class, GPT-6 Luna barely beats guessing.
- **A simple baseline goes far.** TF-IDF reaches 91.6% in a few minutes on a normal CPU. Its strongest words are telling: human writers use *bzw*, AI polishing writes it out as *beziehungsweise*.
- **Doing well on the test set isn't enough.** On academic texts, mmBERT-small, mmBERT-base and GELECTRA-large are practically tied. On texts from new sources, only mmBERT-base and GELECTRA-large stay strong, and mmBERT-small falls to 81%. Testing on unseen kinds of text is what separated them.
- **Light polishing is the hardest to catch.** DeepSeek's AI-assisted texts are missed far more often than those of other AI models, because DeepSeek keeps more of the original wording. When a rewrite keeps over 90% of the words, the detector misses 22% of them.
- **Short texts are unreliable.** Under 70 words, every model gets clearly worse.

## The data

| | |
|---|---|
| Human texts | 10,227 from SSOAR, peDOCS and Refubium (FU Berlin), 1990–2022, open licences only |
| AI models | GPT-5.6 Luna, GPT-6 Luna, Gemini 3.8 Flash, DeepSeek V4 Flash |
| Total | 30,629 texts, almost perfectly balanced across the three classes |
| Split | 24,986 train / 2,906 validation / 2,737 test, by document, so no paper appears in two splits |
| Licence | CC BY-SA 4.0, with author, title and source kept for every text |
| Availability | Kept private on Hugging Face; the code to rebuild it is in steps 01–04 |

Shortcuts the detector could have learned were removed on purpose: human chunks always end on a full sentence, and old German spelling (*daß*) is converted to the new rules, so neither gives the answer away.

As a sanity check, a commercial AI detector (Pangram) classified all 100 sampled human and AI-generated texts correctly, so the AI texts really read as AI-written ([step 03](03_pangram-test/)).

## Tools

- **Data:** OAI-PMH harvesting, PyMuPDF, Azure OpenAI, Gemini and DeepSeek APIs
- **Models:** scikit-learn, Hugging Face Transformers, temperature scaling for calibrated probabilities
- **MLOps:** dataset and models on the Hugging Face Hub, experiment tracking with MLflow

## Limits

- Trained only on **German academic texts** (mostly social sciences and education research) and **four AI models**. Other kinds of text or newer AI models may be detected less well.
- **AI-assisted writing can take many forms.** Here it means one kind: the whole text rewritten and polished by an AI model with the same instructions.
- Texts are cut after **512 tokens**, so only the beginning of long texts is read.
- The output is a **probability, not proof**. It shouldn't be used on its own to accuse anyone of using AI.

## Getting started

```bash
git clone https://github.com/aliissa824/German-AI-Text-Detector-from-scratch.git
cd German-AI-Text-Detector-from-scratch
pip install -r requirements.txt
```

Copy `.env.example` to `.env` and fill in the keys you need: API keys only for steps 02, 03 and 05, and `HF_TOKEN` for the Hugging Face Hub. The dataset is private, so steps 05–09, which load it from the Hub, need access to it. The trained models are public. Each step has its own README with a "How to run" section.
